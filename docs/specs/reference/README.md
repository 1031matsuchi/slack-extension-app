# 外部参照資料置き場（docs/specs/reference/）

このディレクトリには、`SPEC-NNNN` として正式仕様化する前の元資料を格納します。

- 例: Slack API・Block Kit の画面モック（Block Kit Builder の JSON）、外部API（Gemini / Google Calendar 等）の仕様メモ、既存業務フローの調査メモ
- 実装の正本はあくまで親ディレクトリ（[`docs/specs/`](../README.md)）の `SPEC-NNNN-*.md` および基本・詳細設計書です。
- APIキー・トークン・個人情報を含む資料は置かないでください。
- 元資料から仕様書へ反映が完了した際も、経緯追跡のため必要に応じて SPEC から参照リンクを残してください。
