# 個別要件定義書：年間行事予定インポーター（GAS Web アプリ）

- **対象サブシステム**: `gas/excel-calendar-importer/`
- **親文書**: [`REQUIREMENTS.md`](REQUIREMENTS.md)

---

## 1. 目的と位置づけ

年度初め等に配布される年間行事予定の Excel ファイル（表記揺れを含む）をブラウザからアップロードし、AI（Gemini）で予定情報を抽出して **複数の校内共有 Google カレンダー** へ一括登録するための独立した Web アプリケーションです。

---

## 2. 確定している方針・要件

| 項目 | 確定内容 |
| :--- | :--- |
| **実行基盤・配置** | Google Apps Script（GAS）Web アプリとして実装し、本リポジトリの `gas/excel-calendar-importer/` 配下にモノレポ同居する。 |
| **公開・認証方式（案B）** | チーム共通 Google アカウント（`akitacore.stamina@gmail.com`）で **「自分として実行」** 形式でデプロイし、アプリ画面側で **簡易パスコード認証** を行う。 |
| **登録先カレンダー** | 年度替わりやグループ切り替えに対応した **複数の校内共有 Google カレンダー** を対象とする（個人マイカレンダーは対象外）。 |
| **AI モデル方針** | **`gemini-3.8-flash`** を採用（思考レベル `thinkingLevel` を `minimal` または `low` に制御）。開発検証時に無料枠キーを使う場合は架空データのみ使用し、実データ入力は厳禁とする。 |
| **登録後の修正運用** | 取り込み後の予定変更・削除は原則として Google カレンダー上で手動修正する（Excel 再取り込みによる上書き機能は設けない）。 |

---

## 3. 業務フロー

1. 予定管理者が GAS Web アプリの URL を開き、簡易パスコードを入力して認証する。
2. 登録先の校内共有 Google カレンダーを選択し、年間行事予定 Excel ファイルをアップロードする。
3. システムが Excel 内容を AI で解析し、抽出された予定を対象カレンダーへ一括登録する。
4. 登録完了（およびエラー有無）の結果サマリーを画面に表示する。
