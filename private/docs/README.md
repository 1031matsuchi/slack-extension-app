# 開発記録・意思決定ドキュメント（private/docs/）

このディレクトリ（`private/docs/`）は、開発過程の意思決定記録（ADR）、日次作業記録（日報）、PR作成・レビュー時の下書きメモを管理します。

---

## ディレクトリ構成

| パス | 用途 | テンプレート | Git管理 |
| :--- | :--- | :--- | :--- |
| [`adr/`](adr/README.md) | アーキテクチャ意思決定記録（Architecture Decision Records） | [`adr/TEMPLATE.md`](adr/TEMPLATE.md) | 管理する（チームで共有） |
| `daily/` | 日次開発ログ・調査記録・作業引き継ぎメモ（`YYYY-MM-DD.md`） | [`daily/TEMPLATE.md`](daily/TEMPLATE.md) | 管理しない（テンプレートのみ共有） |
| [`pr/`](pr/README.md) | PR説明文の下書き、大規模PRの分割計画、レビュー検証メモ | | 管理しない（README のみ共有） |
| `notes/` | 一時的な調査メモ・スクラッチノート | | 管理しない |

## 文書作成の原則（読み手非依存）

- **誰がいつ読んでも分かる記述**: 「さっきの議論の通り」「AIの提案により」といった文脈依存の表現を避け、背景・比較した選択肢・採用理由を自己完結して記述します。
- **ソースコードへの内部番号だけの記載禁止**: 本番コードのコメントに `ADR-0001` や日報の日付だけを書いて説明を省略しないでください。コード側には、初学者が読んでも分かるように「なぜそうするのか」の理由を直接1〜2行で記述します（[`AGENTS.md`](../../AGENTS.md) の説明コメント規約）。
- **秘密情報を書かない**: トークン・APIキー・DB接続URL・個人情報は、Git管理外のファイルであっても記載しないでください。
